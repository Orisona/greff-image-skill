# Greff — помощник для работы с изображениями

Скилл и все исходники товаров в одном комплекте. Помощник сам объяснит порядок работы после подключения.

## 1. Скачайте и распакуйте

На GitHub нажмите **Code → Download ZIP**.

- **Windows:** нажмите правой кнопкой на архив → **Извлечь всё**.
- **Mac:** дважды нажмите на архив в Finder.

Положите распакованную папку, например, в **Документы**. Сохраните всё её содержимое вместе, включая скрытую папку `.agents`. Работайте из распакованной папки, а не из архива.

## 2. Откройте папку в приложении

Установите [приложение ChatGPT](https://learn.chatgpt.com/docs/app) для Windows или Mac и войдите в аккаунт.

Откройте распакованную папку как **локальный проект**. Выберите папку, в которой находится этот README. В существующем проекте: **Edit project → Add folder**.

Начните чат в **ChatGPT Work с доступом к локальным файлам** или в **Codex**. Если приложение запросит доступ к папке, предоставьте его. Обычному веб-чату недостаточно написать путь к файлам; локальная работа должна быть доступна в вашем аккаунте.

## 3. Подключите помощника

Скопируйте в чат:

```text
Прочитай .agents/skills/greff-image-prompts/SKILL.md в текущем проекте и следуй этой инструкции. Прочитай каталог исходников, проверь доступ к материалам и начни работу с короткого приветствия и выбора действия.
```

Готово — дальше помощник подскажет, что делать, и выполнит работу в этом же чате. Образцы смесителей уже включены в скилл: загружать их каждый раз не нужно, достаточно написать название модели и нужный цвет.

В Codex скилл также может появиться в меню как **Greff — изображения по образцам**. Команда выше позволяет применить инструкцию напрямую из файла, даже если пункта в меню нет.

Если нужны свои референсы сцены или обложки, положите их в Работа/Название-задачи/Референсы внутри проекта и сообщите папку. Прикреплять каждый файл не нужно. Если папки ещё нет, помощник подскажет и поможет её создать.
